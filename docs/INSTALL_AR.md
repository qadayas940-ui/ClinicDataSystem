# دليل تثبيت نظام إدارة العيادة

هذا الدليل خاص بنسخة Windows التي يتم إخراجها باسم `ClinicDataSystem-Setup-1.0.0.exe`.

## التثبيت

1. شغّل ملف التصطيب.
2. اختر مجلد البرنامج، أو اترك المسار المقترح.
3. اختر مجلد بيانات العيادة. هذا المجلد يحتوي قاعدة البيانات والمرفوعات والنسخ الاحتياطية، ولا يُحذف عند تحديث البرنامج أو إلغاء تثبيته.
4. اترك خيار اختصار سطح المكتب مفعلاً عند الحاجة.
5. بعد انتهاء التثبيت شغّل البرنامج وأنشئ حساب المالك من شاشة الإعداد الأولى.

يفتح التطبيق محلياً على:

`http://127.0.0.1:8765`

## التشغيل اليومي

شغّل الاختصار من سطح المكتب. يعمل الخادم على جهاز العيادة، وتُحفظ البيانات في مجلد البيانات الذي اخترته أثناء التثبيت.

لإيقاف النظام أغلق نافذة التطبيق. لا تحذف مجلد البيانات يدوياً.

## استخدام أجهزة متعددة داخل العيادة

من شاشة **أجهزة العيادة** فعّل الوصول داخل الشبكة المحلية، ثم أعد تشغيل البرنامج. افتح العنوان الذي يعرضه النظام من أجهزة المنظمين المتصلة بنفس شبكة العيادة.

لا تفتح منفذ التطبيق مباشرة على الإنترنت. الوصول من خارج العيادة يحتاج VPN أو بوابة HTTPS موثوقة.

## التحديث

ثبّت الإصدار الجديد فوق الإصدار السابق. لا تغيّر مجلد البيانات، ولا تحذف النسخة القديمة قبل التأكد من أن النظام يعمل وأن النسخ الاحتياطية موجودة.

قبل الترحيلات ينشئ النظام نسخة أمان تلقائية من قاعدة البيانات، كما ينشئ نسخة يومية عند التشغيل.

## النسخ الاحتياطي والاستعادة

احتفظ بنسخ مجلد `backups` في مكان منفصل وآمن. لا ترفع ملفات المرضى إلى خدمات عامة أو مستودعات Git.

لاستعادة نسخة احتياطية يفضّل إيقاف التطبيق أولاً ثم تنفيذ الأمر التالي من مجلد المشروع:

```powershell
python manage.py restore_backup "D:\Backups\ClinicData-....clinicbackup" --confirm
```

## بناء ملف التصطيب للمطور

يحتاج البناء إلى Windows مع Python 3.12 وPyInstaller وInno Setup 6:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-build.txt
python manage.py test
pyinstaller --clean --noconfirm ClinicDataSystem.spec
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\ClinicDataSystem.iss
```

ينتج الملف النهائي داخل:

`release\ClinicDataSystem-Setup-1.0.0.exe`

## بيانات المرضى

استخدم نسخة اختبارية عند تجربة التثبيت. لا يغيّر النظام ملف Excel الأصلي، ولا يدمج السجلات المكررة تلقائياً. راجع سياسة الأمان في `SECURITY.md` قبل إدخال بيانات تشغيلية.
