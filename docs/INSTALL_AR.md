# دليل تثبيت نظام إدارة العيادة

هذا الدليل خاص بنسخة Windows التي يتم إخراجها باسم `ClinicDataSystem-Setup-1.3.0.exe`.

## التثبيت

1. شغّل ملف التصطيب.
2. اختر مجلد البرنامج، أو اترك المسار المقترح.
3. اختر مجلد بيانات العيادة. يُستخدم هذا المجلد على جهاز الخادم المحلي فقط، ولا يُحذف عند تحديث البرنامج أو إلغاء تثبيته.
4. على أجهزة الموظفين أدخل رابط الخادم المركزي الذي يقدمه مسؤول النظام. اتركه فارغاً فقط عند تثبيت الجهاز المضيف المحلي.
5. اترك خيار اختصار سطح المكتب مفعلاً عند الحاجة.
6. بعد انتهاء التثبيت شغّل البرنامج. إنشاء حساب المالك يتم مرة واحدة على الخادم، ثم يسجل كل موظف بحسابه وصلاحياته.

عند ترك رابط الخادم فارغاً، يفتح التطبيق محلياً على:

`http://127.0.0.1:8765`

## التشغيل اليومي

شغّل الاختصار من سطح المكتب. نسخة الموظف تفتح الخادم المركزي ولا تنشئ قاعدة بيانات منفصلة. جهاز الخادم المحلي وحده يشغّل الخدمة ويحفظ البيانات في المجلد المختار.

لإيقاف النظام أغلق نافذة التطبيق. لا تحذف مجلد البيانات يدوياً.

## استخدام أجهزة متعددة داخل العيادة

من شاشة **أجهزة العيادة** على الجهاز المضيف فعّل الوصول داخل الشبكة المحلية، ثم أعد تشغيل البرنامج. يظهر رابط مثل `http://192.168.1.25:8765` ويتغير حسب عنوان الجهاز والشبكة. أدخل هذا الرابط أثناء تثبيت نسخ الموظفين.

في النشر عبر الإنترنت يكون رابط HTTPS المركزي واحداً لكل أجهزة العيادة؛ الذي يختلف هو حساب المستخدم وصلاحياته، وليس قاعدة البيانات أو عنوانها. لا يُنشأ لكل تنزيل رابط إنترنت مستقل لأن ذلك سيقسم البيانات بدلاً من مزامنتها.

لا تفتح منفذ التطبيق مباشرة على الإنترنت. الوصول من خارج العيادة يحتاج VPN أو بوابة HTTPS موثوقة.

## التحديث

ثبّت الإصدار الجديد فوق الإصدار السابق. لا تغيّر مجلد البيانات، ولا تحذف النسخة القديمة قبل التأكد من أن النظام يعمل وأن النسخ الاحتياطية موجودة.

قبل الترحيلات ينشئ النظام نسخة أمان تلقائية من قاعدة البيانات، كما ينشئ نسخة يومية عند التشغيل.

## النسخ الاحتياطي والاستعادة

احتفظ بنسخ مجلد `backups` في مكان منفصل وآمن. لا ترفع ملفات المرضى إلى خدمات عامة أو مستودعات Git.

لاستعادة نسخة احتياطية يفضّل إيقاف التطبيق أولاً ثم تنفيذ الأمر التالي من مجلد المشروع:

```powershell
python manage.py restore_backup "C:\ClinicBackups\ClinicData-....clinicbackup" --confirm
```

## بناء ملف التصطيب للمطور

يحتاج البناء إلى Windows مع Python 3.12 وPyInstaller وInno Setup 6:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-build.txt
python manage.py test
pyinstaller --clean --noconfirm ClinicDataSystem.spec
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\ClinicDataSystem.iss
```

ينتج الملف النهائي داخل:

`release\ClinicDataSystem-Setup-1.3.0.exe`

## بيانات المرضى

استخدم نسخة اختبارية عند تجربة التثبيت. لا يغيّر النظام ملف Excel الأصلي، ولا يدمج السجلات المكررة تلقائياً. راجع سياسة الأمان في `SECURITY.md` قبل إدخال بيانات تشغيلية.
