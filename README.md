# نظام إدارة بيانات ومرضى العيادة — ClinicDataSystem

نظام سطح مكتب لإدارة بيانات ومرضى العيادة، مبني على Django مع واجهة عربية
RTL، يعمل كتطبيق سطح مكتب عبر Waitress + pywebview، وقاعدة بيانات SQLite
قابلة للانتقال إلى PostgreSQL لاحقاً.

> هذه المرحلة 1: النواة، الحسابات والصلاحيات، تسجيل الدخول، فحص الصحة،
> الشاشة الرئيسية، ومشغّل سطح المكتب. نماذج بقية التطبيقات جاهزة كأساس
> للمراحل التالية.

## المتطلبات
- Python 3.10 أو أحدث
- نظام تشغيل Windows (للنسخة التشغيلية) أو Linux/macOS للتطوير

## التثبيت
```bash
python -m venv .venv
# تفعيل البيئة الافتراضية ثم:
pip install -r requirements.txt
cp .env.example .env   # عدّل القيم حسب حاجتك
```

## التشغيل (بيئة التطوير)
```bash
python manage.py migrate
python manage.py runserver
# افتح المتصفح على http://127.0.0.1:8000
```
عند أول تشغيل ستُوجَّه إلى صفحة إعداد حساب المالك: `/accounts/setup-owner/`.

## التشغيل كتطبيق سطح مكتب
```bash
python launcher.py
```
يشغّل خادم Waitress على المنفذ 8765 ويفتح نافذة سطح المكتب.

## فحص الصحة
- واجهة برمجية: `GET /api/health/` تُعيد JSON بحالة النظام.
- شاشة عربية: `/health/`.

## الاختبارات
```bash
python manage.py test tests
```

## البنية
- `config/` إعدادات Django (base/development/testing/production).
- `apps/` تطبيقات النظام.
- `templates/` القوالب العربية RTL.
- `static/` الملفات الثابتة (CSS/JS/الشعار).
- `data/` بيانات التطبيق (قاعدة البيانات، المرفوعات، السجلات) — لا تُرفع على Git.
- `scripts/` سكربتات الإعداد والتشغيل.
- `tests/` الاختبارات.

## الأمان
- كلمات المرور تُخزَّن مُجزّأة بخوارزمية Argon2.
- لا تُسجَّل بيانات حساسة في السجلات.
- قفل الحساب بعد 5 محاولات دخول فاشلة لمدة 10 دقائق.
- حذف ناعم (Soft Delete) لجميع النماذج الأساسية.
